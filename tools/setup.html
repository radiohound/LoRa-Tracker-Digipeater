LoRa APRS + Horus Tracker Setup

Connect the tracker with its USB-serial cable, read its settings, change them and save. Nothing leaves this page.

Not connected.

This browser has no Web Serial. Use Chrome or Edge on a computer (not a phone), and open this page over https or from a saved file.

The tracker listens for commands while it waits for a GPS fix, in its receive window, and in setup mode. If it does not answer, press Reset on the board and press Connect within 3 seconds: the page sends a key, which opens setup mode. A program that already has the serial port open (a terminal, pio device monitor) must be closed first.

The callsign is still N0CALL: no LoRa APRS is sent until you set one.

Actions

A beacon cycle waits for a GPS fix first (up to the GPS timeout). Setup mode, if you are in it, holds the tracker until you leave it or restart.

Update the firmware (USB cable)
  1. Choose the firmware below (or your own .bin).
  2. Connect first if you can: the page then puts the tracker into its bootloader for you. Otherwise hold Key 1 (the middle button) and tap Reset, and keep holding Key 1 for about a second.
  3. Press Flash firmware and pick the board's USB port. It takes about half a minute.
